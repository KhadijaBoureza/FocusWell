==================================================
PROJECT OVERVIEW
==================================================

FocusWell is a full-stack productivity and digital wellbeing
dashboard designed to help users manage tasks, focus sessions,
reminders, notes, and personal reflections within one unified
interface.

The application combines productivity and wellbeing tools
including:
- task management
- Pomodoro focus timer
- reminders
- calendar organisation
- wellbeing tracking
- analytics and achievements

The project was developed using React, TypeScript, Node.js,
Express.js, and MongoDB Atlas.

==================================================
DEPENDENCIES
==================================================

All required dependencies are already listed inside:

- frontend/package.json
- backend/package.json

To automatically install all dependencies, run:

inside BOTH the frontend and backend folders.

==================================================
HOW TO RUN THE PROJECT
==================================================

STEP 1 — Extract the ZIP archive.

STEP 2 — Open the project folder in Visual Studio Code.

==================================================
FRONTEND SETUP
==================================================

1. Open a terminal inside the frontend folder.

2. Install frontend dependencies:

npm install

3. Start the frontend development server:

npm run dev

4. Open the browser using the URL shown in the terminal.

Usually:

http://localhost:5173

OR

http://localhost:8080

==================================================
BACKEND SETUP
==================================================

1. Open a second terminal inside the backend folder.

2. Install backend dependencies:

npm install

3. Start the backend server:

npm start

OR

node server.js

(depending on configuration)
